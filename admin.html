如何生成 Token？（展开查看）
  1. 打开 GitHub，右上角头像 → Settings → Developer settings → Personal access tokens
  2. 选择 Fine-grained tokens，点击 Generate new token
  3. Token name 随意填写；Repository access 选择 Only select repositories，勾选 moment 仓库
  4. Permissions 里把 Contents 设为 Read and write（Metadata 会自动跟随）
  5. 生成后把 token 粘贴到上方输入框，点击「保存并验证」
